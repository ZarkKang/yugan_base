## 1. 系统架构概述

### 1.1 无人机端整体架构

无人机端运行在 NVIDIA Jetson NX 平台上，基于 ROS Noetic 框架。系统由**飞控层**和**载荷层**两个独立子系统组成：

```
┌──────────────────────────────────────────────────────────────────────┐
│                      无人机端 (NVIDIA Jetson NX)                       │
│                                                                        │
│  ┌──────────────────────── 飞控层 (不改动) ─────────────────────────┐ │
│  │                                                                   │ │
│  │  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────────────┐ │ │
│  │  │ PX4 飞控  │  │ MAVROS   │  │ FAST-LIO2│  │ EGO-Planner      │ │ │
│  │  │ (姿态控制) │  │ (MAVLink) │  │ (SLAM)   │  │ (路径规划)       │ │ │
│  │  └─────┬─────┘  └────┬─────┘  └────┬─────┘  └────────┬─────────┘ │ │
```

### 1.2 子系统职责划分

| 子系统 | 路径 | 职责 | 是否可修改 |
|--------|------|------|-----------|
| `uav_ground_bridge` | `src/payload/uav_ground_bridge/` | 数据桥接：心跳、RFID、位置、电池、航点监控、视频推流 | **是（开发目标）** |
| RFID 驱动节点 | `src/payload/rfid_driver/`（或独立节点） | 串口读写 PRE 协议，发布 `/rfid/tags` 话题 | 是 |
| PX4 飞控 | 飞控固件 | 姿态控制、电机驱动 | 否 |
| MAVROS | `mavros` 包 | MAVLink 桥接，提供 `/Odometry`、`/mavros/battery` | 否 |
| FAST-LIO2 | 规划层 | 激光 SLAM 定位 | 否 |
| EGO-Planner | 规划层 | 路径规划 | 否 |

### 1.3 数据流全景

```
[硬件]                          [ROS 话题]                  [uav_ground_bridge]          [地面基站]
 ─────────────────────────────────────────────────────────────────────────────────────────────────
 RFID 读卡器 ──串口──▶ rfid_driver ──▶ /rfid/tags ──▶ rfid_bridge ──缓存5s──▶ POST /gateway/receive
                                                               │
 PX4/MAVROS ──▶ /Odometry ──▶ heartbeat ──▶ POST /drones/{code}/heartbeat (每5s)
              ──▶ /mavros/battery ──▶ (可选)
                                                               │
 摄像头 ──▶ /dev/video0 ──▶ uav_video_stream ──ffmpeg──▶ UDP 192.168.1.100:5600
                                                               │
 waypoints.yaml ──▶ waypoint_monitor ──到达航点──▶ 触发 RFID 扫描 ──▶ 汇总上传
```

## 3. 硬件兼容性要求

### 3.1 UHF RFID 读卡器

| 参数 | 规格 |
|------|------|
| 型号 | PRE 系列超高频 RFID 一体化模块 |
| 协议版本 | V2.2 |
| 通讯协议 | 二进制帧格式 (Header=0xBB, End=0x7E) |
| 接口 | 串口 (TTL / RS232) |
| 默认波特率 | 115200 bps（也支持 9600） |
| 连接方式 | USB 转串口 → `/dev/ttyUSB0` |
| 频率范围 | 902-928 MHz (FCC) / 865-868 MHz (ETSI) |
| 标签协议 | ISO 18000-6C (EPC Gen2) |

**RFID 驱动节点职责**：
- 通过串口与 PRE 模块通信
- 发送盘存命令 (CMD_INVENTORY / CMD_READ_MULTI)
- 解析二进制帧响应
- 提取 EPC、RSSI、PC、CRC
- 发布到 ROS 话题 `/rfid/tags`（消息类型: `std_msgs/String`，内容为 JSON）

**PRE 协议帧格式**：

```
┌──────┬──────┬──────┬──────┬──────┬──────┬──────────┬──────┬──────┐
│Header│ Type │ Cmd  │ PL(Hi)│PL(Lo)│ 参数  │ 校验和    │ End  │
│ 0xBB │1 byte│1 byte│1 byte │1 byte│N bytes│ 2 bytes  │ 0x7E │
└──────┴──────┴──────┴──────┴──────┴──────┴──────────┴──────┴──────┘
```

基站端参考实现：[rfid_reader.py](file:///e:/A0.software/The%20computer%20files/桌面/域感智能/warehouse-inspection-system/backend/src/hardware/rfid_reader.py)

### 3.2 摄像头

| 参数 | 规格 |
|------|------|
| 接口 | USB |
| 设备路径 | `/dev/video0` |
| 支持格式 | MJPEG / YUYV |
| 默认分辨率 | 640×480 |
| 帧率 | 30fps |

## 4. API 接口规范

> **关键**: 所有 HTTP 端点路径前缀统一为 `/api/warehouse`。  
> 基站接口详情见 [doc/无人机端开发规范.md](file:///e:/A0.software/The%20computer%20files/桌面/域感智能/doc/无人机端开发规范.md) 第 3 章。

### 4.1 接口总览

| 编号 | 方法 | 端点 | 用途 | 频率 | 超时 |
|------|------|------|------|------|------|
| API-01 | POST | `/api/v1/drones/{drone_code}/heartbeat` | 心跳上报 | 5s | 3s |
| API-02 | POST | `/api/v1/gateway/receive` | RFID 数据上传 | 到达航点 | 10s |
| API-03 | POST | `/api/v1/gateway/receive` | 图像上传 | 按需 | 30s |
| API-04 | POST | `/api/v1/gateway/receive` | 二维码上传 | 按需 | 10s |
| API-05 | UDP | `udp://192.168.1.100:5600` | 视频推流 | 持续 | N/A |
| API-06 | POST | `/api/v1/drone-integration/device/report` | 设备身份上报 | 启动1次 | 10s |

### 4.2 API-01: 心跳上报

```python
POST /api/v1/drones/{drone_code}/heartbeat
Content-Type: application/json

{
    "drone_code": "DRONE001",
    "status": "flying",
    "battery": 85.5,
    "position": {"x": 1.5, "y": 2.0, "z": 3.0},
    "timestamp": 1781874689.7
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `drone_code` | string | 是 | 无人机编号，需与基站已注册的一致 |
| `status` | string | 是 | `idle` / `flying` / `returning` / `error` |
| `battery` | float | 是 | 电量百分比 (0-100)，无数据传 `-1` |
| `position.x/y/z` | float | 是 | 坐标 (m) |
| `timestamp` | float | 是 | Unix 时间戳 (秒) |

**响应** (200): `{"success": true, "message": "心跳已接收", "data": null}`  
**响应** (404): `{"detail": "无人机不存在: DRONE001"}`

### 4.5 接口调用通用模板

```python
import requests
import json
import time

GROUND_URL = "http://192.168.1.100:8001"
DRONE_CODE = "DRONE001"
API_PREFIX = "/api/warehouse"
TIMEOUT = 3

def post_to_ground(endpoint, data, timeout=TIMEOUT):
    """通用 POST 请求封装"""
    url = f"{GROUND_URL}{API_PREFIX}{endpoint}"
    try:
        resp = requests.post(url, json=data, timeout=timeout)
        resp.raise_for_status()
        return resp.json()
    except requests.exceptions.Timeout:
        print(f"[WARN] 请求超时: {url}")
        return None
    except requests.exceptions.ConnectionError:
        print(f"[WARN] 基站不可达: {url}")
        return None
    except requests.exceptions.RequestException as e:
        print(f"[WARN] 请求失败: {e}")
        return None
```

## 5. 数据通信协议

### 5.1 通信拓扑

```
链路1: HTTP 数据链路
  无人机 (192.168.1.201) ──POST──▶ 基站 (192.168.1.100:8001)
  协议: HTTP/1.1, Content-Type: application/json
  路径前缀: /api/warehouse
  特性: 请求-响应模式，单向发起（无人机→基站）

链路2: UDP 视频链路
  无人机 (192.168.1.201) ──UDP──▶ 基站 (192.168.1.100:5600)
  协议: MPEG-TS over UDP
  编码: H.264 → MPEG-TS
  特性: 单向推流，无握手，低延迟
```

### 5.2 ROS 话题定义

| 话题 | 消息类型 | 方向 | 说明 |
|------|---------|------|------|
| `/rfid/tags` | `std_msgs/String` | 订阅 | RFID 标签数据 (JSON) |
| `/Odometry` | `nav_msgs/Odometry` | 订阅 | 无人机里程计/位置 |
| `/mavros/local_position/pose` | `geometry_msgs/PoseStamped` | 订阅(备选) | MAVROS 位置 |
| `/mavros/battery` | `sensor_msgs/BatteryState` | 订阅(可选) | 电池状态 |

### 5.3 RFID 标签数据格式 (ROS)

**话题**: `/rfid/tags`  
**消息类型**: `std_msgs/String`  
**内容** (JSON):

```json
{
    "epc": "E280F3372000F0001A72CDCE",
    "rssi_dbm": -62,
    "pc": "3400",
    "crc": "DEE0",
    "stamp": 1781874689.7
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `epc` | string | EPC 标签号 (hex 大写, 24 字符) |
| `rssi_dbm` | int | 信号强度 (dBm)，范围 -90 ~ -30 |
| `pc` | string | Protocol Control 字段 |
| `crc` | string | CRC 校验值 |
| `stamp` | float | ROS 时间戳 (秒) |

### 5.4 航点文件格式 (YAML)

**路径**: `src/payload/uav_ground_bridge/config/waypoints.yaml`

```yaml
task_code: TASK001
waypoints:
  - id: 1
    x: 0.0
    y: 0.0
    z: 1.5
    dwell_time: 5.0
  - id: 2
    x: 2.0
    y: 0.0
    z: 1.5
    dwell_time: 3.0
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `task_code` | string | 是 | 任务编号，需与基站一致 |
| `waypoints[].id` | int | 是 | 航点序号 (从 1 开始) |
| `waypoints[].x` | float | 是 | X 坐标 (m) |
| `waypoints[].y` | float | 是 | Y 坐标 (m) |
| `waypoints[].z` | float | 是 | Z 坐标 / 高度 (m) |
| `waypoints[].dwell_time` | float | 是 | 悬停扫描时长 (秒) |

### 5.5 失败日志格式 (JSONL)

**路径**: `src/payload/uav_ground_bridge/logs/uav_ground_bridge_failed.jsonl`

```json
{"timestamp": "2026-06-21T10:30:00Z", "endpoint": "/api/v1/drones/DRONE001/heartbeat", "method": "POST", "payload": {...}, "error": "Connection refused", "retry_count": 0}
```

### 5.6 视频推流协议

```bash
# 编码链路
摄像头 → /dev/video0 → v4l2 → ffmpeg → H.264 编码 → MPEG-TS 封装 → UDP 发送

# 参数
输入:     -f v4l2 -input_format mjpeg -video_size 640x480 -framerate 30 -i /dev/video0
编码:     -c:v libx264 -preset ultrafast -tune zerolatency -b:v 1500k
封装:     -f mpegts
输出:     udp://192.168.1.100:5600
```

### 6.2 模块1: 心跳发送节点 (heartbeat_node.py)

**功能**: 定时向基站发送无人机心跳，包含位置、电量、状态。

**实现要点**:

```
┌─────────────────────────────────────────────────────────┐
│  heartbeat_node.py                                       │
│                                                          │
│  初始化:                                                 │
│    1. 读取 ROS 参数 (ground_url, drone_code, interval)   │
│    2. 订阅 /Odometry (nav_msgs/Odometry)                 │
│    3. 订阅 /mavros/battery (sensor_msgs/BatteryState)    │
│    4. 创建 rospy.Timer (interval=5s)                     │
│                                                          │
│  定时回调 _send_heartbeat():                             │
│    1. 构造 JSON payload                                  │
│    2. POST {ground_url}/api/v1/drones/{code}/heartbeat│
│    3. 成功 → rospy.logdebug                              │
│    4. 失败 → rospy.logwarn + 写入失败日志                │
│                                                          │
│  订阅回调 _on_odom(msg):                                 │
│    更新 self.position = {x, y, z}                        │
│                                                          │
│  订阅回调 _on_battery(msg):                              │
│    更新 self.battery = msg.percentage * 100              │
└─────────────────────────────────────────────────────────┘
```

**伪代码骨架**:

```python
#!/usr/bin/env python3
import rospy
import requests
import json
import time
import os
from nav_msgs.msg import Odometry
from sensor_msgs.msg import BatteryState

class HeartbeatNode:
    def __init__(self):
        rospy.init_node("heartbeat_node")
        self.ground_url = rospy.get_param("~ground_url", "http://192.168.1.100:8001")
        self.drone_code = rospy.get_param("~drone_code", "DRONE001")
        self.interval = rospy.get_param("~heartbeat_interval", 5.0)

        self.position = {"x": 0.0, "y": 0.0, "z": 0.0}
        self.battery = -1.0
        self.status = "idle"

        # 订阅
        odom_topic = rospy.get_param("~odom_topic", "/Odometry")
        self.odom_sub = rospy.Subscriber(odom_topic, Odometry, self._on_odom)

        try:
            self.battery_sub = rospy.Subscriber(
                "/mavros/battery", BatteryState, self._on_battery
            )
        except Exception:
            rospy.logwarn("无法订阅电池话题")

        # 定时器
        self.timer = rospy.Timer(rospy.Duration(self.interval), self._send_heartbeat)

        # 日志目录
        self.log_dir = os.path.join(
            os.path.dirname(__file__), "..", "logs"
        )
        os.makedirs(self.log_dir, exist_ok=True)

        rospy.loginfo(f"心跳节点已启动: drone={self.drone_code}, interval={self.interval}s")

    def _on_odom(self, msg):
        self.position = {
            "x": msg.pose.pose.position.x,
            "y": msg.pose.pose.position.y,
            "z": msg.pose.pose.position.z,
        }

    def _on_battery(self, msg):
        if msg.percentage is not None:
            self.battery = msg.percentage * 100.0

    def _send_heartbeat(self, event):
        url = f"{self.ground_url}/api/v1/drones/{self.drone_code}/heartbeat"
        payload = {
            "drone_code": self.drone_code,
            "status": self.status,
            "battery": self.battery,
            "position": self.position,
            "timestamp": time.time(),
        }
        try:
            resp = requests.post(url, json=payload, timeout=3)
            if resp.status_code == 200:
                rospy.logdebug(f"心跳成功: {resp.json()}")
            else:
                rospy.logwarn(f"心跳失败: HTTP {resp.status_code}")
                self._log_failed(url, payload, f"HTTP {resp.status_code}")
        except requests.exceptions.RequestException as e:
            rospy.logwarn(f"心跳异常: {e}")
            self._log_failed(url, payload, str(e))

    def _log_failed(self, url, payload, error):
        log_path = os.path.join(self.log_dir, "uav_ground_bridge_failed.jsonl")
        record = json.dumps({
            "timestamp": time.strftime("%Y-%m-%dT%H:%M:%SZ", time.gmtime()),
            "endpoint": url,
            "method": "POST",
            "payload": payload,
            "error": error,
            "retry_count": 0,
        })
        with open(log_path, "a") as f:
            f.write(record + "\n")

    def run(self):
        rospy.spin()
```

### 6.3 模块2: RFID 数据桥接节点 (rfid_bridge_node.py)

**功能**: 订阅 `/rfid/tags` 话题，缓存标签数据，在航点到达时汇总上传。

**实现要点**:

```
┌─────────────────────────────────────────────────────────┐
│  rfid_bridge_node.py                                     │
│                                                          │
│  初始化:                                                 │
│    1. 读取参数 (ground_url, drone_code, cache_window_s)  │
│    2. 订阅 /rfid/tags (std_msgs/String)                  │
│    3. 维护 tags_cache = []  (带时间戳的标签列表)          │
│                                                          │
│  订阅回调 _on_rfid_tag(msg):                             │
│    1. 解析 JSON → {epc, rssi_dbm, pc, crc, stamp}       │
│    2. append 到 tags_cache                               │
│                                                          │
│  方法 get_cached_tags(window_s=5):                       │
│    1. 过滤最近 window_s 秒内的标签                        │
│    2. 去重 (按 epc)                                      │
│    3. 返回去重后的标签列表                                │
│                                                          │
│  方法 upload_scan(waypoint_id, task_code):               │
│    1. 调用 get_cached_tags()                             │
│    2. 构造 upload payload (含 metadata)                   │
│    3. POST /api/v1/gateway/receive                │
│    4. 清空缓存                                           │
└─────────────────────────────────────────────────────────┘
```

**伪代码骨架**:

```python
class RfidBridgeNode:
    def __init__(self):
        rospy.init_node("rfid_bridge_node")
        self.tags_cache = []  # [{epc, rssi_dbm, pc, crc, stamp}, ...]
        self.cache_window = rospy.get_param("~cache_window_s", 5.0)

        rfid_topic = rospy.get_param("~rfid_topic", "/rfid/tags")
        self.rfid_sub = rospy.Subscriber(rfid_topic, String, self._on_rfid_tag)

    def _on_rfid_tag(self, msg):
        try:
            tag = json.loads(msg.data)
            self.tags_cache.append(tag)
            # 限制缓存大小
            if len(self.tags_cache) > 1000:
                self.tags_cache = self.tags_cache[-500:]
        except json.JSONDecodeError:
            rospy.logwarn(f"无效 RFID 数据: {msg.data[:100]}")

    def get_cached_tags(self, window_s=None):
        """获取缓存窗口内的去重标签"""
        if window_s is None:
            window_s = self.cache_window
        now = time.time()
        recent = [t for t in self.tags_cache if now - t.get("stamp", 0) <= window_s]
        # 按 epc 去重，保留最新
        seen = {}
        for t in recent:
            epc = t.get("epc")
            if epc and epc not in seen:
                seen[epc] = t
        return list(seen.values())

    def upload_scan(self, waypoint_id, task_code, position, battery):
        """上传 RFID 扫描结果到基站"""
        tags = self.get_cached_tags()
        if not tags:
            rospy.loginfo(f"航点 {waypoint_id}: 未扫描到标签")
            return

        payload = {
            "drone_code": self.drone_code,
            "data_type": "rfid",
            "payload": json.dumps(tags),
            "timestamp": time.strftime("%Y-%m-%dT%H:%M:%SZ", time.gmtime()),
            "position_x": position["x"],
            "position_y": position["y"],
            "position_z": position["z"],
            "metadata": {
                "task_code": task_code,
                "waypoint_id": waypoint_id,
                "event": "waypoint_completed",
                "video_stream": "udp://@:5600",
                "battery": battery,
                "timestamp": time.time(),
            },
        }

        url = f"{self.ground_url}/api/v1/gateway/receive"
        try:
            resp = requests.post(url, json=payload, timeout=10)
            if resp.status_code == 200:
                rospy.loginfo(f"航点 {waypoint_id}: 上传 {len(tags)} 个标签成功")
                self.tags_cache.clear()
            else:
                rospy.logwarn(f"上传失败: HTTP {resp.status_code}")
        except requests.exceptions.RequestException as e:
            rospy.logwarn(f"上传异常: {e}")
```

### 6.4 模块3: 航点到达监控 (waypoint_monitor.py)

**功能**: 读取航点文件，实时判断是否到达航点，触发 RFID 扫描。

**实现要点**:

```
┌─────────────────────────────────────────────────────────┐
│  waypoint_monitor.py                                     │
│                                                          │
│  初始化:                                                 │
│    1. 读取 waypoints.yaml                                │
│    2. 订阅 /Odometry (位置)                              │
│    3. 初始化 current_waypoint_index = 0                  │
│    4. 初始化 arrival_timer = None                        │
│                                                          │
│  主循环 (10Hz):                                          │
│    1. 获取当前位置                                       │
│    2. 获取当前目标航点                                   │
│    3. 计算距离 = sqrt((x-x0)^2 + (y-y0)^2 + (z-z0)^2)  │

│       - 如果 arrival_timer 未启动 → 启动                │
│       - 如果 arrival_timer >= arrival_hold_time (2s):   │
│         → 触发 on_waypoint_arrived()                     │
│         → current_waypoint_index += 1                    │
│    5. 否则 → 重置 arrival_timer                         │
│                                                          │
│  on_waypoint_arrived():                                  │
│    1. rospy.loginfo("到达航点 {id}")                     │
│    2. 等待 dwell_time 秒 (悬停扫描)                      │
│    3. 调用 rfid_bridge.upload_scan()                     │
│    4. 如果所有航点完成 → 上报任务完成                    │
```

```python
import subprocess
import rospy

class VideoStreamNode:
    def __init__(self):
        rospy.init_node("video_stream_node")
        self.device = rospy.get_param("~video_device", "/dev/video0")
        self.target_host = rospy.get_param("~video_target_host", "192.168.1.100")
        self.target_port = rospy.get_param("~video_target_port", 5600)
        self.width = rospy.get_param("~video_width", 640)
        self.height = rospy.get_param("~video_height", 480)
        self.fps = rospy.get_param("~video_fps", 30)
        self.bitrate = rospy.get_param("~video_bitrate", "1500k")

        self.process = None

    def start(self):
        cmd = [
            "ffmpeg",
            "-f", "v4l2",
            "-input_format", "mjpeg",
            "-video_size", f"{self.width}x{self.height}",
            "-framerate", str(self.fps),
            "-i", self.device,
            "-c:v", "libx264",
            "-preset", "ultrafast",
            "-tune", "zerolatency",
            "-b:v", self.bitrate,
            "-f", "mpegts",
            f"udp://{self.target_host}:{self.target_port}",
        ]
        rospy.loginfo(f"启动视频推流: {' '.join(cmd)}")
        self.process = subprocess.Popen(cmd, stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL)

    def stop(self):
        if self.process:
            self.process.terminate()
            self.process.wait()
            rospy.loginfo("视频推流已停止")
```

## 7. 安全认证机制

### 7.1 当前安全状态

| 层级 | 当前状态 | 说明 |
|------|---------|------|
| 传输加密 | 无 | HTTP 明文传输，数据不加密 |
| 身份认证 | 无 | 无人机以 `drone_code` 字符串标识自身，无签名/令牌 |
| 数据完整性 | 无 | 无数字签名或 HMAC 校验 |
| 防重放 | 无 | 无 timestamp + nonce 机制 |
| 访问控制 | 无 | 基站不验证请求来源 |

### 7.2 后续安全增强计划

**Phase 1: API Key 认证（短期）**

```
无人机端在请求头中携带 API Key：
  Authorization: Bearer <drone_api_key>

基站端在 gateway 中间件中验证 API Key。
```

**Phase 2: HTTPS + 双向 TLS（中期）**

```
启用 HTTPS 传输加密。
基站和无人机互相验证证书。
```

**Phase 3: 请求签名 + 防重放（长期）**

```
每个请求携带:
  - X-Timestamp: Unix 时间戳
  - X-Nonce: 随机数 (一次性)
  - X-Signature: HMAC-SHA256(payload + timestamp + nonce, shared_secret)

基站验证:
  1. timestamp 在 ±30s 窗口内
  2. nonce 未使用过
  3. signature 正确
```

### 7.3 无人机端安全编码规范


**2. RFID 缓存优化**

```python
# 使用 collections.deque 限制缓存大小，避免内存无限增长
from collections import deque

class RfidCache:
    def __init__(self, max_size=500):
        self._cache = deque(maxlen=max_size)

    def add(self, tag):
        self._cache.append(tag)

    def get_recent(self, window_s=5.0):
        now = time.time()
        return [t for t in self._cache if now - t["stamp"] <= window_s]
```

**5. 线程安全**

```python
# 多节点共享数据时使用 threading.Lock
import threading

class SharedState:
    def __init__(self):
        self._lock = threading.Lock()
        self.position = {"x": 0, "y": 0, "z": 0}
        self.battery = -1.0

    def update_position(self, x, y, z):
        with self._lock:
            self.position = {"x": x, "y": y, "z": z}

    def get_position(self):
        with self._lock:
            return dict(self.position)
```

### D. 错误码速查

| HTTP 状态码 | 含义 | 无人机端处理 |
|------------|------|-------------|
| 200 | 成功 | 正常处理 |
| 400 | 请求格式错误 | 检查 data_type 和 payload 格式 |
| 404 | 无人机未注册 | 确认 drone_code 在基站已注册 |
| 503 | 服务器繁忙 | 等待后重试 |
| 超时 | 基站不可达 | 写入本地失败日志，不崩溃 |
| 连接拒绝 | 基站未启动 | 写入本地失败日志，等待恢复 |
