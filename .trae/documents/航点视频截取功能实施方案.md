# 航点视频截取功能实施方案

## Context

当前系统：无人机持续 WS 推流，到达航点时仅标记帧位置（`waypoint_markers`），不截取独立视频片段。用户需要：当无人机到达航点时，从 WS 实时图传流中截取一段短视频（可配置延迟+时长），截取后自动走 QR 识别后处理管线，配置参数持久化到数据库。

## 步骤 5-6：Clip 截取核心机制

### 方案：独立 clip VideoWriter 旁路写入

在 `_writer_loop` 中，每写完一帧到主 writer 后，同步喂给所有活跃 clip writer。clip 写完指定帧数后自动关闭并触发后处理。

### ClipWriterContext 数据类

```python
@dataclass
class ClipWriterContext:
    waypoint_id: str
    writer: cv2.VideoWriter
    output_path: str
    fps: int
    max_frames: int       # = duration_seconds * fps
    frames_written: int = 0
    start_time: datetime = None
    expected_sku: Optional[str] = None
    task_code: Optional[str] = None
    drone_id: int = 0
    drone_code: str = ""
    position: Optional[dict] = None
    position_warning: Optional[str] = None
```

### DroneStreamSession 修改

- 新增 `_clip_writers: Dict[str, ClipWriterContext]` + `_clip_lock: threading.Lock`
- `start_clip_capture(waypoint_id, expected_sku, max_frames, ...)` — 创建 clip VideoWriter，输出路径 `clip_{waypoint_id}_{ts}.mp4`
- `_feed_clips(img)` — 在 `_writer_loop` 的 `writer.write(img)` 之后调用，遍历 `_clip_writers` 喂帧，写满自动调用 `_finish_clip()`
- `_finish_clip(clip_ctx)` — 关闭 writer → 创建 VideoData(`source="waypoint_clip"`) → 启动 `postprocess_video` 线程
- 同一 session 最多 1 个活跃 clip（避免多航点并行截取的复杂度）

### `_writer_loop` 修改点

```python
writer.write(img)
self.frame_count += 1
# ↓ 新增：喂给活跃 clip writer
self._feed_clips(img)
```

### VideoStreamAggregator 新增

```python
def schedule_clip_capture(self, drone_id, waypoint_id, expected_sku=None, position=None) -> dict:
    """
    1. 读配置 (capture_enabled, delay, duration, tolerance)
    2. 位置校验（与 Waypoint.position 比较）
    3. delay=0 → 立即 start_clip_capture()
    4. delay>0 → threading.Timer(delay, ...) 延迟启动
    Returns: {"scheduled": bool, "position_warning": str|None, "message": str}
    """
```

位置校验用欧氏距离：`sqrt(dx²+dy²+dz²) > tolerance` → 记录警告但仍可截取（软验证）。

## 验证方式

1. **启动服务**：`python -m src.main` → 确认 `system_configs` 表创建 + 4 条种子数据
2. **配置 CRUD**：`GET /api/v1/config/clip` → 返回默认值；`PUT` 修改后 `GET` 确认持久化
3. **WS 推流 + 航点截取**：启动 WS 连接 → 发送 `waypoint_enter` → 确认 clip 文件生成 → VideoData 记录 `source="waypoint_clip"` → postprocess 自动触发
4. **位置校验**：提供偏差 > 0.2m 的 position → 响应中含 `position_warning`
5. **延迟截取**：设置 `delay_seconds=3` → 航点到达后 3 秒才开始写 clip 文件
6. **前端**：打开截取设置页 → 修改参数 → 保存 → 刷新确认持久化
