# 域感智能 - 开发任务清单

> 优先级排序: P0(阻塞核心流程) > P1(重要功能) > P2(体验优化) > P3(基础设施)

---

## P0 - 阻塞核心流程

### Task 1: 修复无人机模拟器全流程
**问题**: 模拟器 404（DRONE001 未 seeded）+ 旧进程未加载新代码

**步骤**:
1. WSL 执行: `sudo -u postgres psql -d warehouse_inspection -c "INSERT INTO drones (drone_code, drone_name, model, status, serial_number) VALUES ('DRONE001','测试无人机','DJI-M300','offline','TEST-SN-001') ON CONFLICT (drone_code) DO NOTHING;"`
2. 重启仓库系统: `pkill -f "uvicorn.*port=8001" && sleep 1 && MODE=hybrid bash 启动.sh start`
3. 测试模拟器: `引导.sh` → `功能测试` → `无人机模拟器`
4. 预期: health → 心跳 → 获取任务 → 全部通过

**文件**: `warehouse-inspection-system/backend/src/db/seed.py` (已改，需重启生效)

---

### Task 2: 实现 RFID WSL 串口通信
**问题**: `/dev/ttyS6` pyserial 配置失败，fd 回退未验证

**步骤**:
1. WSL 授权: `sudo chmod 666 /dev/ttyS6`
2. 测试连接: `引导.sh` → `功能测试` → `RFID读卡器测试`
3. 如 fd 方式不通，尝试安装 `wslu` 或用 Windows Python 直连 COM7
4. 验证能读到 EPC 标签

**文件**: `warehouse-inspection-system/backend/src/hardware/rfid_reader.py`

---

### Task 3: 实现 Gateway 数据接收与处理
**问题**: 核心数据流未打通

**步骤**:
1. 实现 `receive_data()` - 接收无人机上传的原始数据（图像/视频帧/传感器）
2. 实现 `_process_background_task()` - 异步处理队列（图像识别、数据存储）
3. 实现 `process_qrcode()` - 调用 `qr_service.py` 识别二维码
4. 实现 `receive_rfid()` - 调用 `rfid_reader.py` 读取标签
5. 端到端测试: 模拟器 → gateway → 后端处理 → 数据库

**文件**: `warehouse-inspection-system/backend/src/api/gateway.py`

---

## P1 - 重要功能

### Task 4: 实现无人机 CRUD 完整接口

**步骤**:
1. `get_drone(drone_id)` - 查询详情（已有 `get_drone_by_code` 内部方法）
2. `update_drone()` - 更新无人机信息（名称/型号/状态）
3. `delete_drone()` - 删除无人机（检查关联任务）
4. `get_drone_position()` - 接入无人机数据系统 8000 的位置数据

**文件**: `warehouse-inspection-system/backend/src/api/drones.py`

---

### Task 5: 实现巡检记录 CRUD

**步骤**:
1. `create_record()` - 创建巡检记录（绑定任务/无人机/时间）
2. `get_records()` - 分页查询（按任务/日期/状态筛选）
3. `get_record()` - 详情（含关联图像/异常记录）
4. `update_record()` - 更新状态/备注
5. `delete_record()` - 删除（软删除标记）

**文件**: `warehouse-inspection-system/backend/src/api/inspection.py`

---

### Task 6: 安装 libzbar0 启用 QR 识别

**步骤**:
1. `sudo apt install libzbar0`
2. 验证: `引导.sh` → `功能测试` → `QR码识别测试` → 显示 "pyzbar: 可用"
3. 端到端测试: 上传含 QR 码的图片 → 识别返回结果

**文件**: 系统级安装，无代码变更
