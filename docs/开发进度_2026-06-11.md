## 架构决策

### 运行模式: 混合架构 (Hybrid)
| 组件 | 部署方式 | 原因 |
|------|----------|------|
| PostgreSQL | 本地 Linux | WSL Docker 镜像下载不稳定 |
| Redis | 本地 Linux | 同上 |
| 后端服务 | 本地 venv + uvicorn | 快速迭代，RFID/串口需本地访问 |
| 前端 | 浏览器直接打开 | 无构建步骤 |
| 引导菜单 | 独立 `引导.sh` 脚本 | 交互式菜单，不修改现有 `启动.sh` |

| 仓库巡检系统 | 8001 | HTTP |
| API 网关 | 8080 | HTTP |
