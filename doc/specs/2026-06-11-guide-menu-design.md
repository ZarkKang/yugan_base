# 引导菜单设计文档

> 日期: 2026-06-11
> 文件: `引导.sh`

## 概述

新建独立脚本 `引导.sh`，提供终端交互式菜单，覆盖部署、管理、测试、维护四大功能模块。不修改现有 `启动.sh`，保持向后兼容。

## 架构

- 使用 Bash `select` 构建两级菜单（主菜单 → 子菜单 → 执行）
- 运行模式通过 `.mode.conf` 文件持久化（docker/local/hybrid）
- 所有子功能复用 `启动.sh` 的现有逻辑

## 主菜单

```
╔══════════════════════════════════════════╗
║          域感智能 - 系统引导菜单          ║
║          运行模式: [混合模式]             ║
╚══════════════════════════════════════════╝

  1) 🚀 环境部署
  2) ⚙️ 服务管理
  3) 🧪 功能测试
  4) 🔧 系统维护
  5) ℹ️  系统信息
  6) ❌ 退出
```

## 子菜单

### 1) 环境部署
- 快速部署（全自动）
- 仅检测环境
- 安装系统依赖
- 初始化数据库
- 配置 PiP 镜像源
- 设置运行模式

### 2) 服务管理
- 启动/停止/重启所有服务
- 查看服务状态/日志
- 启动/停止单个服务
- 切换运行模式

### 3) 功能测试
- 运行无人机模拟器
- 测试 RFID 读卡器
- 测试 QR 码识别
- API 连通性测试
- 数据库连通性测试

### 4) 系统维护
- 清理虚拟环境
- 清理日志文件
- 重置数据库（需确认）
- 更新系统代码
- 检查端口占用

### 5) 系统信息
- Python/PostgreSQL/Docker 版本
- 服务状态和端口
- 磁盘使用

## 运行模式

| 模式 | 值 | 说明 |
|------|-----|------|
| Docker | `docker` | 全部 docker-compose |
| 本地 | `local` | 全部本地服务 |
| 混合 | `hybrid` | 基础设施Docker + 后端本地（默认） |

## 安全设计

- 危险操作（重置数据库/清理 venv）→ 二次确认
- 彩色输出复用现有颜色变量
- Ctrl+C 优雅退出
- 错误后返回子菜单，不退出脚本
