```
│  ┌─────────────────┐          ┌─────────────────┐         │
│  │   基站端        │          │   无人机端       │         │
```

### 1.2 数据流

```
无人机端 (192.168.1.201)
│
│  1. 任务请求:  GET /api/tasks/available
│  2. 心跳上报:  POST /api/drones/heartbeat
│  3. 图像识别:  POST /api/scan/upload  (实时)
│  4. 图传流:    WebSocket ws://192.168.1.200:8080/ws/video
│  5. 状态更新:  POST /api/tasks/{task_id}/progress
│  └─────────────────┐
│                    ▼
│
基站端 (192.168.1.200)
│
│  FastAPI + PostgreSQL + WebSocket
│  ├── 任务管理: 创建/分配/监控
│  ├── 数据接收: 扫码结果/图像/RFID
│  ├── 异常判定: 视觉 vs 库存比对
│  ├── 报告生成: 盘点报告 + 证据图
│  └── 图传中继: 实时画面转发给前端
│
▼
桌面应用 (Electron)
├── 任务管理界面
├── 实时监控大屏
├── 报告查看/导出
└── 无人机状态监控
```

## 二、无人机端功能（机载软件）

### 2.1 无人机端架构

```
Jetson NX (Ubuntu 22.04 + ROS2 Humble)
│
├── 路径规划节点 (path_planner_node)
│   ├── A* 路径规划
│   └── 轨迹优化
│
├── 视觉处理节点 (vision_node)
│   ├── 摄像头采集
│   ├── QR码检测与解码
│   ├── 图像质量评分
│   └── 识别结果上报
│
├── RFID节点 (rfid_node)
│   └── RFID标签读取与复核
│
├── 避障控制节点 (obstacle_node)
│   ├── 激光雷达数据
│   └── DWA避障
│
└── 数据上传节点 (upload_node)
    ├── HTTP REST API 上传扫码数据
    ├── WebSocket 实时图传
    └── 心跳保持
```

### 2.2 无人机端核心功能清单

| 功能 | 说明 | 接口 |
|------|------|------|
| **任务获取** | 从基站获取待执行任务 | `GET /api/drones/{drone_id}/tasks/available` |
| **任务执行** | 按航点顺序执行扫描 | - |
| **扫码识别** | 采集图像并识别QR码 | `POST /api/scan/upload` |
| **RFID复核** | 异常时触发RFID读取 | `POST /api/scan/upload` (type=rfid) |
| **实时图传** | WebSocket推流 | `ws://192.168.1.200:8080/ws/video/{drone_id}` |
| **心跳上报** | 每5秒上报运行状态 | `POST /api/drones/heartbeat` |
| **状态监控** | 电池/位置/任务进度 | - |
| **固件升级** | 从基站获取新版本固件 | `GET /api/drones/firmware/latest` |

#### 4.2.1 基站通信客户端

```python
# drone-onboard/src/base_station_client.py
import requests
import json
from typing import Optional, Dict, List

class BaseStationClient:
    """与基站通信的HTTP客户端"""

    def __init__(self, config: dict):
        self.base_url = f"http://{config['ip']}:{config['port']}"
        self.drone_id = config['drone_id']
        self.session = requests.Session()
        self.retry_count = config.get('retry_count', 3)
        self.retry_interval = config.get('retry_interval', 5)

    def get_available_tasks(self) -> List[dict]:
        """从基站获取可执行任务"""
        url = f"{self.base_url}/api/drones/{self.drone_id}/tasks/available"
        response = self._request("GET", url)
        return response.json() if response else []

    def accept_task(self, task_id: str) -> bool:
        """确认接收任务"""
        url = f"{self.base_url}/api/drones/{self.drone_id}/tasks/{task_id}/accept"
        response = self._request("POST", url)
        return response is not None and response.status_code == 200

    def get_task_waypoints(self, task_id: str) -> List[dict]:
        """获取任务航点列表"""
        url = f"{self.base_url}/api/tasks/{task_id}/waypoints"
        response = self._request("GET", url)
        return response.json() if response else []

    def upload_scan(self, scan_data: dict) -> Optional[dict]:
        """上传单个扫码结果"""
        url = f"{self.base_url}/api/scan/upload"
        response = self._request("POST", url, json=scan_data)
        return response.json() if response else None

    def upload_scan_batch(self, scans: List[dict]) -> bool:
        """批量上传（网络不稳定时使用）"""
        url = f"{self.base_url}/api/scan/batch"
        response = self._request("POST", url, json=scans)
        return response is not None and response.status_code == 200

    def send_heartbeat(self, status_data: dict) -> bool:
        """发送心跳"""
        url = f"{self.base_url}/api/drones/heartbeat"
        response = self._request("POST", url, json=status_data)
        return response is not None and response.status_code == 200

    def update_task_progress(self, task_id: str, progress: dict) -> bool:
        """上报任务进度"""
        url = f"{self.base_url}/api/drones/{self.drone_id}/tasks/{task_id}/progress"
        response = self._request("POST", url, json=progress)
        return response is not None and response.status_code == 200

    def complete_task(self, task_id: str, summary: dict) -> bool:
        """完成任务上报"""
        url = f"{self.base_url}/api/drones/{self.drone_id}/tasks/{task_id}/complete"
        response = self._request("POST", url, json=summary)
        return response is not None and response.status_code == 200

    def _request(self, method: str, url: str, **kwargs) -> Optional[requests.Response]:
        """带重试的请求"""
        for attempt in range(self.retry_count):
            try:
                response = self.session.request(method, url, timeout=10, **kwargs)
                response.raise_for_status()
                return response
            except (requests.RequestException, ValueError):
                if attempt < self.retry_count - 1:
                    import time
                    time.sleep(self.retry_interval)
                continue
        return None
```

```python
import websocket
import threading
import time

from typing import Callable

class VideoStreamClient:
    """WebSocket图传客户端（无人机端）"""

    def __init__(self, config: dict, on_message: Callable = None):
        self.ws_url = f"ws://{config['ip']}:{config['port']}/ws/video/{config['drone_id']}"
        self.ws = None
        self.connected = False
        self.reconnect_interval = 5

    def connect(self):
        """连接到基站"""
        try:
            self.ws = websocket.create_connection(self.ws_url, timeout=10)
            self.connected = True
            # 启动接收线程
            threading.Thread(target=self._receive_loop, daemon=True).start()
            return True
        except Exception:
            self.connected = False
            return False

    def send_frame(self, frame_data: bytes, frame_info: dict = None):
        """发送图像帧"""
        if not self.connected or not self.ws:
            return False

        try:
            # 先发送元信息
            if frame_info:
                self.ws.send(json.dumps(frame_info))

            # 再发送二进制图像数据
            self.ws.send(frame_data, opcode=websocket.ABNF.OPCODE_BINARY)
            return True
        except Exception:
            self.connected = False
            return False

    def disconnect(self):
        """断开连接"""
        if self.ws:
            try:
                self.ws.close()
            except Exception:
                pass
        self.connected = False

    def _receive_loop(self):
        """接收基站消息（如暂停/继续指令）"""
        while self.connected and self.ws:
            try:
                message = self.ws.recv()
                if message:
                    # 处理基站下发的控制指令
                    pass
            except Exception:
                self.connected = False
```

#### 4.2.3 QR码识别（增强版）

```python
# drone-onboard/src/vision/qr_decoder.py
import cv2
import numpy as np
from pyzbar.pyzbar import decode as pyzbar_decode
from typing import Optional, Tuple

class EnhancedQRDecoder:
    """增强版QR码解码器"""

    def __init__(self, config: dict):
        self.min_confidence = config.get('min_confidence', 0.7)
        self.quality_threshold = config.get('quality_threshold', 50.0)
        self.max_rescan_attempts = config.get('max_rescan_attempts', 3)
        self.scales = [0.5, 0.75, 1.0, 1.25, 1.5, 2.0]
        self.preprocess_strategies = [
            'original', 'gaussian_blur', 'bilateral_filter',
            'histogram_eq', 'adaptive_threshold', 'sharpen'
        ]

    def decode(self, image: np.ndarray) -> Optional[Tuple[str, float]]:
        """
        多尺度、多策略解码
        返回: (qr_data, confidence)
        """
        gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)

        for scale in self.scales:
            if scale != 1.0:
                resized = cv2.resize(gray, None, fx=scale, fy=scale)
            else:
                resized = gray

            for strategy in self.preprocess_strategies:
                processed = self._preprocess(resized, strategy)
                result = self._single_decode(processed)
                if result:
                    return result

        return None

    def estimate_quality(self, image: np.ndarray) -> float:
        """图像质量评分（拉普拉斯方差）"""
        gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY) if len(image.shape) == 3 else image
        laplacian = cv2.Laplacian(gray, cv2.CV_64F)
        return laplacian.var()

    def _preprocess(self, image: np.ndarray, strategy: str) -> np.ndarray:
        """预处理"""
        if strategy == 'original':
            return image
        elif strategy == 'gaussian_blur':
            return cv2.GaussianBlur(image, (3, 3), 0)
        elif strategy == 'bilateral_filter':
            return cv2.bilateralFilter(image, 9, 75, 75)
        elif strategy == 'histogram_eq':
            return cv2.equalizeHist(image)
        elif strategy == 'adaptive_threshold':
            return cv2.adaptiveThreshold(image, 255, cv2.ADAPTIVE_THRESH_GAUSSIAN_C, cv2.THRESH_BINARY, 11, 2)
        elif strategy == 'sharpen':
            kernel = np.array([[-1,-1,-1], [-1,9,-1], [-1,-1,-1]])
            return cv2.filter2D(image, -1, kernel)
        return image

    def _single_decode(self, image: np.ndarray) -> Optional[Tuple[str, float]]:
        """单次解码"""
        barcodes = pyzbar_decode(image)
        if barcodes:
            confidence = self.estimate_quality(image)
            # 将质量评分映射到0-1区间
            normalized_conf = min(1.0, confidence / 1000.0)
            return (barcodes[0].data.decode('utf-8'), normalized_conf)
        return None
```

#### 4.2.4 主程序流程

```python
# drone-onboard/src/main.py
"""
无人机主程序流程：
1. 加载配置（含基站IP 192.168.1.200）
2. 初始化传感器（摄像头、RFID、激光雷达）
3. 连接基站
4. 获取任务
5. 执行任务（航点巡航 → 扫码 → 上传）
6. 完成任务，生成报告
"""

import time
import threading
from datetime import datetime

from config import load_config
from base_station_client import BaseStationClient
from websocket_client import VideoStreamClient
from vision.camera import Camera
from vision.qr_decoder import EnhancedQRDecoder
from rfid.rfid_reader import RFIDReader
from planner.path_planner import PathPlanner
from control.drone_controller import DroneController

def main():
    # 1. 加载配置
    config = load_config('/etc/drone/drone_config.yaml')
    drone_id = config['drone']['id']

    # 2. 初始化客户端
    base_client = BaseStationClient(config['drone']['base_station'])
    video_client = VideoStreamClient(config['drone']['base_station'])

    # 3. 初始化硬件
    camera = Camera(config['drone']['camera'])
    qr_decoder = EnhancedQRDecoder(config['drone']['scan'])
    rfid_reader = RFIDReader(config['drone']['rfid'])
    planner = PathPlanner(config['drone']['path_planning'])
    controller = DroneController()

    # 4. 启动心跳线程
    heartbeat_thread = threading.Thread(
        target=heartbeat_loop,
        args=(base_client, drone_id, controller),
        daemon=True
    )
    heartbeat_thread.start()

    # 5. 启动图传线程
    video_thread = threading.Thread(
        target=video_stream_loop,
        args=(video_client, camera),
        daemon=True
    )
    video_thread.start()

    # 6. 主循环：获取并执行任务
    while True:
        try:
            # 获取可用任务
            tasks = base_client.get_available_tasks()

            if not tasks:
                print("无可用任务，等待中...")
                time.sleep(30)
                continue

            # 选择第一个任务执行
            task = tasks[0]
            task_id = task['task_id']
            print(f"开始执行任务: {task_id}")

            # 接收任务
            base_client.accept_task(task_id)

            # 获取航点
            waypoints = base_client.get_task_waypoints(task_id)
            print(f"共 {len(waypoints)} 个航点")

            # 执行航点
            for idx, waypoint in enumerate(waypoints):
                waypoint_id = waypoint['waypoint_id']

                # a. 飞行到航点
                success = controller.fly_to(
                    waypoint['position']['x'],
                    waypoint['position']['y'],
                    waypoint['position']['z']
                )
                if not success:
                    print(f"航点 {waypoint_id} 飞行失败，跳过")
                    continue

                # b. 扫码
                scan_result = scan_and_upload(
                    camera=camera,
                    qr_decoder=qr_decoder,
                    rfid_reader=rfid_reader,
                    base_client=base_client,
                    waypoint=waypoint,
                    task_id=task_id,
                    drone_id=drone_id
                )

                # c. 上报进度
                base_client.update_task_progress(task_id, {
                    "scanned": idx + 1,
                    "total": len(waypoints)
                })

            # 7. 完成任务
            base_client.complete_task(task_id, {
                "total_scanned": len(waypoints),
                "normal_count": scan_result['normal_count'] if 'scan_result' in dir() else 0,
                "abnormal_count": scan_result['abnormal_count'] if 'scan_result' in dir() else 0,
                "completed_at": datetime.utcnow().isoformat()
            })

            print(f"任务 {task_id} 完成")

        except KeyboardInterrupt:
            print("用户中断，停止飞行")
            controller.land()
            break
        except Exception as e:
            print(f"发生错误: {e}")
            time.sleep(10)
            continue

def heartbeat_loop(base_client: BaseStationClient, drone_id: str, controller: DroneController):
    """心跳循环：每5秒上报一次"""
    while True:
        try:
            status = controller.get_status()  # 电池/位置/状态
            base_client.send_heartbeat({
                "drone_id": drone_id,
                "battery": status['battery'],
                "status": status['mode'],
                "position": status['position'],
                "current_task": status['current_task'],
                "current_waypoint": status['current_waypoint'],
                "last_heartbeat": datetime.utcnow().isoformat()
            })
        except Exception:
            pass
        time.sleep(5)

def video_stream_loop(video_client: VideoStreamClient, camera: Camera):
    """图传循环：持续发送视频帧到基站"""
    frame_count = 0
    while True:
        try:
            # 尝试连接
            if not video_client.connected:
                video_client.connect()
                if not video_client.connected:
                    time.sleep(5)
                    continue

            # 采集并发送图像
            frame = camera.capture()
            if frame is not None:
                # JPEG编码（压缩后更小，传输更快）
                _, encoded = cv2.imencode('.jpg', frame, [cv2.IMWRITE_JPEG_QUALITY, 70])
                frame_data = encoded.tobytes()

                # 发送帧信息 + 二进制数据
                video_client.send_frame(
                    frame_data,
                    {
                        "frame_id": frame_count,
                        "timestamp": datetime.utcnow().isoformat(),
                        "size": len(frame_data),
                        "format": "jpeg"
                    }
                )
                frame_count += 1

            # ~30fps，但受网络影响自适应
            time.sleep(0.033)

        except Exception as e:
            print(f"图传错误: {e}")
            time.sleep(1)

def scan_and_upload(camera, qr_decoder, rfid_reader, base_client, waypoint, task_id, drone_id):
    """
    扫码并上传的核心流程
    """
    # 1. 采集图像
    frame = camera.capture()
    if frame is None:
        return None

    # 2. 图像质量评估
    quality = qr_decoder.estimate_quality(frame)

    # 3. 尝试解码
    decode_result = qr_decoder.decode(frame)
    qr_data = None
    confidence = 0.0

    if decode_result:
        qr_data, confidence = decode_result

    # 4. 如果解码失败或置信度过低，重试
    attempts = 0
    while (not qr_data or confidence < qr_decoder.min_confidence) and attempts < qr_decoder.max_rescan_attempts:
        time.sleep(0.5)  # 稍微等待
        frame = camera.capture()
        if frame is None:
            attempts += 1
            continue

        decode_result = qr_decoder.decode(frame)
        if decode_result:
            qr_data, confidence = decode_result
        attempts += 1

    # 5. 如果仍未识别，触发RFID复核（可选）
    rfid_tags = []
    if not qr_data:
        rfid_tags = rfid_reader.read()

    # 6. 保存图像（用于证据图）
    image_url = f"http://192.168.1.200:8080/images/{drone_id}_{task_id}_{waypoint['waypoint_id']}.jpg"
    # 这里简化处理，实际需要HTTP上传或共享存储

    # 7. 组装并上传数据
    scan_data = {
        "drone_id": drone_id,
        "task_id": task_id,
        "waypoint_id": waypoint['waypoint_id'],
        "scan_type": "qr" if qr_data else "rfid" if rfid_tags else "empty",
        "qr_data": qr_data,
        "confidence": confidence,
        "image_quality": quality,
        "image_url": image_url,
        "rfid_tags": rfid_tags,
        "position": {
            "x": waypoint['position']['x'],
            "y": waypoint['position']['y'],
            "z": waypoint['position']['z']
        },
        "timestamp": datetime.utcnow().isoformat()
    }

    # 8. 上传到基站
    result = base_client.upload_scan(scan_data)

    # 9. 根据基站返回的判定结果处理
    if result and result.get('verification'):
        status = result['verification']['status']
        # 如为异常，可触发悬停/减速/重扫等逻辑
        if status != "normal":
            print(f"航点 {waypoint['waypoint_id']} 异常: {status} - {result['verification'].get('message', '')}")

    return result

if __name__ == "__main__":
    main()
```

## 十、常见问题排查

### 10.1 无人机无法连接基站

```bash
# 在无人机上执行
ping 192.168.1.200          # 检查网络连通性
curl http://192.168.1.200:8080/health  # 检查API
# 如返回 "connection refused"：
#   - 基站服务未启动
#   - 防火墙阻止了8080端口
#   - Docker容器未正确映射端口
```

### 10.2 图传延迟高

- 检查网络带宽（建议使用千兆以太网或5G WiFi）
- 降低图像分辨率（如 1280x720）
- 提高JPEG压缩率（降低质量）
- 减少帧率（如15fps）

### 10.3 扫码识别率低

- 检查摄像头对焦
- 调整光照（避免强反光/过暗）
- 启用多策略解码（已在方案中提供）
- 降低飞行速度，增加扫码停留时间
