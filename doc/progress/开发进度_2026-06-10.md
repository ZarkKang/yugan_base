## 当前阻塞问题

### PostgreSQL 无法安装/启动
**原因**: WSL 通过 `/mnt/e/` 访问 Windows 磁盘
- Docker pull 镜像频繁断连（SSL EOF / short read）
- apt install 下载慢且 Docker 源 SSL 报错

**已尝试方案**:
1. Docker Compose + postgres:16-alpine → 镜像下载中断
2. 配置 Docker 镜像加速 → 未生效
3. apt install postgresql → Docker 源 SSL 报错（不影响其他源，但未继续安装）

**建议方案**（待用户执行）:
```bash
# 忽略 Docker 源错误，继续安装
sudo apt install -y postgresql postgresql-contrib redis-server
sudo service postgresql start
sudo service redis-server start
sudo -u postgres psql -c "CREATE DATABASE warehouse_inspection;"
./启动.sh start warehouse
```
