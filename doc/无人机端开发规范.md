## 1. 系统架构

### 1.1 整体架构

```
┌─────────────────────────────────────────────────────────────────┐
│                        无人机端 (NVIDIA Jetson NX)                 │
│                                                                   │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────────────┐ │
│  │ PX4 飞控  │  │ MAVROS   │  │ FAST-LIO2│  │ EGO-Planner      │ │
│  └─────┬─────┘  └────┬─────┘  └────┬─────┘  └────────┬─────────┘ │
│        │              │             │                  │          │
│        ▼              ▼             ▼                  ▼          │
│  ┌─────────────────────────────────────────────────────────────┐ │
│  │              uav_ground_bridge (数据桥接层)                   │ │
│  │  • 心跳上传 (5s)    • RFID 数据订阅/缓存/上传                │ │
│  │  • 航点到达监控     • 位置/电池读取                          │ │
│  │  • 视频推流 (ffmpeg) • 失败重试日志                          │ │
│  └──────────────────────────┬──────────────────────────────────┘ │
│                             │                                     │
│  ┌──────────────────────────┴──────────────────────────────────┐ │
│  │ 硬件层                                                       │ │
│  │  • UHF RFID 读卡器 (串口)   • 摄像头 (/dev/video0)           │ │
│  │  • 网卡 eth1 (192.168.1.201)                                │ │
│  └─────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────┘
         │                           │
         │ HTTP (8001)               │ UDP (5600)
         ▼                           ▼
┌─────────────────────────────────────────────────────────────────┐
│                      地面基站 (Linux Server)                      │
│                                                                   │
│  ┌──────────────────┐  ┌──────────────────┐  ┌───────────────┐  │
│  │ API Gateway :8080│  │ Warehouse :8001  │  │ VLC :5600     │  │
│  │ (统一路由)        │  │ (数据接收/处理)   │  │ (视频查看)     │  │
│  └──────────────────┘  └──────────────────┘  └───────────────┘  │
└─────────────────────────────────────────────────────────────────┘
```

### 1.2 子系统职责

| 系统 | 位置 | 职责 |
|------|------|------|
| `uav_ground_bridge` | 无人机 NX 端 | 数据桥接：心跳、RFID、位置、电池、视频推流。不控制飞行。 |
| `warehouse-inspection-system` | 地面基站 | 数据接收、巡检任务管理、库存管理、RFID 入库 |
| `api-gateway` | 地面基站 | 统一路由 `/api/warehouse/*` → 8001 |

## 2. 通信架构

### 2.1 双链路设计

```
链路1: HTTP 数据链路 (心跳 / RFID / 位置 / 电池)
  无人机 NX (192.168.1.201) ──HTTP POST──▶ 地面基站 (192.168.1.100:8001)
  路径前缀: /api/warehouse

链路2: UDP 视频链路 (实时视频流)
  无人机 NX (192.168.1.201) ──UDP MPEG-TS──▶ 地面基站 (192.168.1.100:5600)
  协议: H.264 → MPEG-TS → UDP
```

**关键特性**：两条链路独立，视频链路不受 HTTP 服务状态影响。地面站 8001 离线时，视频仍可通过 VLC 查看。

### 2.2 网络拓扑

| 参数 | 无人机端 | 地面基站 |
|------|---------|---------|
| 网卡 | eth1 | eth0 / eth1 |
| IP 地址 | 192.168.1.201 | 192.168.1.100 |
| 通信方式 | WiFi 直连 / 局域网 | — |
| 路由验证 | `ip route get 192.168.1.100` | — |

### 2.3 容错机制

- **HTTP 失败**：不崩溃，仅输出 ROS warning 日志
- **失败数据持久化**：写入本地 JSONL 日志 `logs/uav_ground_bridge_failed.jsonl`
- **重试策略**：当前版本无自动重试，需人工补传；后续版本计划加入指数退避重试

## 3. 接口规范

### 3.1 接口总览

| 编号 | 方法 | 端点 | 用途 | 频率 |
|------|------|------|------|------|
| API-01 | POST | `/api/warehouse/drones/{drone_code}/heartbeat` | 心跳上报 | 5s/次 |
| API-02 | POST | `/api/warehouse/gateway/receive` | 航点 RFID 数据上传 | 到达航点时 |
| API-03 | POST | `/api/warehouse/gateway/receive` | 图像数据上传 | 按需 |
| API-04 | POST | `/api/warehouse/gateway/receive` | 二维码数据上传 | 按需 |
| API-05 | UDP | `udp://192.168.1.100:5600` | 视频推流 | 持续 |
| API-06 | POST | `/api/warehouse/drone-integration/device/report` | 设备身份上报 | 启动时1次 |

> **注意**: 所有 HTTP 端点均通过 API 网关（8080）或直接访问 warehouse-inspection-system（8001）。  
> 路径前缀统一为 `/api/warehouse`。

### 3.2 API-01: 心跳上报

```
POST /api/warehouse/drones/{drone_code}/heartbeat
Content-Type: application/json
```

**请求体**:

```json
{
  "drone_code": "DRONE001",
  "status": "idle",
  "battery": 85.5,
  "position": {
    "x": 1.5,
    "y": 2.0,
    "z": 3.0
  },
  "timestamp": 1781874689.7
}
```

**字段说明**:

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `drone_code` | string | 是 | 无人机编号，需与基站注册的 `drone_code` 一致 |
| `status` | string | 是 | 无人机状态: `idle` / `flying` / `returning` / `error` |
| `battery` | float | 是 | 电池电量百分比 (0-100)，无数据时传 `-1` |
| `position.x` | float | 是 | X 坐标 (m) |
| `position.y` | float | 是 | Y 坐标 (m) |
| `position.z` | float | 是 | Z 坐标 (m) |
| `timestamp` | float | 是 | Unix 时间戳 (秒) |

**成功响应** (200):

```json
{
  "success": true,
  "message": "心跳已接收",
  "data": null
}
```

**失败响应** (404):

```json
{
  "detail": "无人机不存在: DRONE001"
}
```

### 3.3 API-02: 航点 RFID 数据上传

当无人机到达航点并完成 RFID 扫描后，将扫描结果汇总上传。

```
POST /api/warehouse/gateway/receive
Content-Type: application/json
```

**请求体**:

```json
{
  "drone_code": "DRONE001",
  "data_type": "rfid",
  "payload": "[{\"epc\":\"E280F3372000F0001A72CDCE\",\"rssi_dbm\":-62,\"pc\":\"3400\",\"crc\":\"DEE0\",\"stamp\":1781874689.7}]",
  "timestamp": "2026-06-21T10:30:00Z",
  "position_x": 1.5,
  "position_y": 2.0,
  "position_z": 3.0,
  "metadata": {
    "task_code": "TASK001",
    "waypoint_id": 1,
    "event": "waypoint_completed",
    "video_stream": "udp://@:5600",
    "battery": 85.5,
    "timestamp": 1781874689.7
  }
}
```

**字段说明**:

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `drone_code` | string | 是 | 无人机编号 |
| `data_type` | string | 是 | 固定为 `"rfid"` |
| `payload` | string | 是 | JSON 字符串，RFID 标签数组，每个元素含 `epc`、`rssi_dbm`、`pc`、`crc`、`stamp` |
| `timestamp` | string | 否 | ISO 8601 时间戳 |
| `position_x` | float | 否 | 无人机 X 坐标 |
| `position_y` | float | 否 | 无人机 Y 坐标 |
| `position_z` | float | 否 | 无人机 Z 坐标 |
| `metadata` | object | 否 | 附加元数据 |

**metadata 子字段**:

| 字段 | 类型 | 说明 |
|------|------|------|
| `task_code` | string | 关联的巡检任务编号 |
| `waypoint_id` | int | 当前航点 ID |
| `event` | string | 事件类型: `waypoint_completed` |
| `video_stream` | string | 视频流地址 |
| `battery` | float | 电池电量 |
| `timestamp` | float | Unix 时间戳 |

**成功响应** (200):

```json
{
  "success": true,
  "message": "数据已接收 (rfid)",
  "record_id": 123
}
```

**失败响应**:

```json
{
  "detail": "无人机不存在: DRONE001"
}
```

### 3.4 API-03: 图像数据上传

```
POST /api/warehouse/gateway/receive
Content-Type: application/json
```

**请求体**:

```json
{
  "drone_code": "DRONE001",
  "data_type": "image",
  "payload": "/9j/4AAQSkZJRg...base64编码的图像数据...",

    "task_code": "TASK001",
    "waypoint_id": 1
  }

```

**payload 格式**:
- 支持纯 Base64 字符串
- 支持 Data URI 格式: `data:image/jpeg;base64,xxx`

```json
{
  "success": true,
  "message": "图像数据已接收，正在后台处理",
  "record_id": null
}
```

> **注意**: 图像数据较大，基站采用异步队列处理。`record_id` 为 null 表示已进入后台队列。

### 3.6 API-05: 视频推流

```
协议: UDP
目标: 192.168.1.100:5600
编码: H.264 → MPEG-TS
工具: ffmpeg
```

**ffmpeg 命令**:

```bash
ffmpeg -f v4l2 -input_format mjpeg -video_size 640x480 -framerate 30 \
  -i /dev/video0 -c:v libx264 -preset ultrafast -tune zerolatency \
  -f mpegts udp://192.168.1.100:5600
```

**地面站接收**:

```bash
# VLC 打开
vlc udp://@:5600

# 或 ffplay 查看
ffplay udp://@:5600
```

### 3.7 API-06: 设备身份上报

无人机启动时向基站上报设备身份信息，基站存储后可通过 passive 模式验证，无需基站主动连接无人机。

```
POST /api/warehouse/drone-integration/device/report
Content-Type: application/x-www-form-urlencoded
```

**请求参数** (Query String):

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `drone_code` | string | 是 | 无人机编号 |
| `ip_address` | string | 是 | 设备IP (默认: 192.168.1.201) |
| `device_model` | string | 否 | 设备型号 (如: NVIDIA Jetson NX) |
| `manufacturer` | string | 否 | 制造商 (默认: NVIDIA) |
| `firmware_version` | string | 否 | 固件/系统版本 |
| `supported_protocols` | string | 否 | 支持的协议，逗号分隔 (默认: HTTP) |
| `port` | int | 否 | HTTP 服务端口 (默认: 8080) |
| `ros_version` | string | 否 | ROS 版本 (如: noetic) |
| `os_version` | string | 否 | 操作系统版本 |
| `cpu_info` | string | 否 | CPU 信息 |
| `memory_mb` | int | 否 | 内存大小 (MB) |

**请求示例**:

```bash
curl -X POST "http://192.168.1.100:8001/api/warehouse/drone-integration/device/report?drone_code=DRONE001&ip_address=192.168.1.201&device_model=NVIDIA%20Jetson%20NX&firmware_version=Ubuntu%2020.04&ros_version=noetic&supported_protocols=HTTP"
```

**成功响应** (200):

```json
{
  "success": true,
  "message": "设备信息已接收",
  "data": {
    "action": "created",
    "device_id": 1,
    "ip_address": "192.168.1.201",
    "device_model": "NVIDIA Jetson NX",
    "firmware_version": "Ubuntu 20.04",
    "supported_protocols": ["HTTP"],
    "ros_version": "noetic",
    "reported_at": "2026-06-21T10:30:00Z"
  }
}
```

**无人机端脚本**: `doc/drone_scripts/report_device_info.py` — 自动采集设备信息并上报，支持重试。

**无人机端 HTTP 服务端** (可选): `doc/drone_scripts/drone_http_server.py` — 轻量 HTTP 服务端，监听 8080 端口，响应基站的 active 模式验证请求。

### 3.8 验证模式说明

基站设备验证支持两种模式：

| 模式 | 方向 | 要求 | 适用场景 |
|------|------|------|---------|
| **passive** (推荐) | 无人机→基站 | 无人机启动时调用 API-06 上报设备信息 | 无人机端无 HTTP 服务端 |
| **active** | 基站→无人机 | 无人机运行 `drone_http_server.py` 监听 8080 | 验证向导需要直接连接无人机 |

## 4. 数据格式规范

### 4.1 RFID 标签数据格式

**ROS 话题**: `/rfid/tags`  
**消息类型**: `std_msgs/String`  
**消息内容** (JSON):

```json
{
  "epc": "E280F3372000F0001A72CDCE",
  "rssi_dbm": -62,
  "pc": "3400",
  "crc": "DEE0",
  "stamp": 1781874689.7
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `epc` | string | EPC 标签号 (hex 大写, 24 字符) |
| `rssi_dbm` | int | 信号强度 (dBm)，范围通常 -90 ~ -30 |
| `pc` | string | PC (Protocol Control) 字段 |
| `crc` | string | CRC 校验值 |
| `stamp` | float | ROS 时间戳 (秒) |

### 4.2 位置数据格式

**ROS 话题**: `/Odometry`（默认）或 `/mavros/local_position/pose`  
**消息类型**: `nav_msgs/Odometry`（默认）或 `geometry_msgs/PoseStamped`

**内部表示**:

```json
{
  "x": 1.5,
  "y": 2.0,
  "z": 3.0
}
```

### 4.3 电池数据格式

**ROS 话题**: `/mavros/battery`（可选）  
**消息类型**: `sensor_msgs/BatteryState`

**内部表示**: `float` (0-100 百分比)，无数据时为 `-1`

### 4.4 航点文件格式

**路径**: `src/payload/uav_ground_bridge/config/waypoints.yaml`

```yaml
task_code: TASK001
waypoints:
  - id: 1
    x: 0.0
    y: 0.0
    z: 1.0
    dwell_time: 5.0
  - id: 2
    x: 2.0
    y: 0.0
    z: 1.0
    dwell_time: 3.0
  - id: 3
    x: 2.0
    y: 2.0
    z: 1.0
    dwell_time: 5.0
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `task_code` | string | 任务编号，需与基站 `tasks` 表一致 |
| `waypoints[].id` | int | 航点序号 |
| `waypoints[].x` | float | X 坐标 (m) |
| `waypoints[].y` | float | Y 坐标 (m) |
| `waypoints[].z` | float | Z 坐标 / 高度 (m) |
| `waypoints[].dwell_time` | float | 悬停扫描时长 (秒) |

### 4.5 失败日志格式

**路径**: `src/payload/uav_ground_bridge/logs/uav_ground_bridge_failed.jsonl`

**每条记录** (JSONL):

```json
{
  "timestamp": "2026-06-21T10:30:00Z",
  "endpoint": "/api/warehouse/drones/DRONE001/heartbeat",
  "method": "POST",
  "payload": {"drone_code": "DRONE001", "status": "idle", "battery": 85.5, "position": {"x": 1.5, "y": 2.0, "z": 3.0}, "timestamp": 1781874689.7},
  "error": "Connection refused",
  "retry_count": 0
}
```

## 6. 技术参数与约束

### 6.1 默认参数

| 参数 | 默认值 | 可配置 | 说明 |
|------|--------|--------|------|
| 心跳间隔 | 5s | ✅ | `heartbeat_interval` 参数 |
| RFID 缓存窗口 | 5s | ✅ | 航点扫描期间缓存 |
| 航点到达半径 | 0.3m | ✅ | `arrival_radius` 参数 |
| 航点停留时间 | 2.0s | ✅ | `arrival_hold_time` 参数 |
| 视频分辨率 | 640x480 | ✅ | `video_width` / `video_height` |
| 视频帧率 | 30fps | ✅ | `video_fps` 参数 |
| 视频码率 | 1500k | ✅ | `video_bitrate` 参数 |

### 9.1 无人机端: 心跳发送 (Python ROS)

```python
#!/usr/bin/env python3
"""uav_ground_bridge 心跳发送节点"""
import rospy
import requests
import json
import time
from nav_msgs.msg import Odometry
from sensor_msgs.msg import BatteryState

class HeartbeatPublisher:
    def __init__(self):
        self.ground_url = rospy.get_param("~ground_url", "http://192.168.1.100:8001")
        self.drone_code = rospy.get_param("~drone_code", "DRONE001")
        self.interval = rospy.get_param("~heartbeat_interval", 5.0)

        self.position = {"x": 0.0, "y": 0.0, "z": 0.0}
        self.battery = -1.0
        self.status = "idle"

        # 订阅位置
        odom_topic = rospy.get_param("~odom_topic", "/Odometry")
        self.odom_sub = rospy.Subscriber(odom_topic, Odometry, self._on_odom)

        # 订阅电池（可选）
        try:
            self.battery_sub = rospy.Subscriber("/mavros/battery", BatteryState, self._on_battery)
        except Exception:
            rospy.logwarn("无法订阅电池话题")

        # 定时发送心跳
        rospy.Timer(rospy.Duration(self.interval), self._send_heartbeat)

    def _on_odom(self, msg: Odometry):
        self.position = {
            "x": msg.pose.pose.position.x,
            "y": msg.pose.pose.position.y,
            "z": msg.pose.pose.position.z,
        }

    def _on_battery(self, msg: BatteryState):
        if msg.percentage is not None:
            self.battery = msg.percentage * 100.0

    def _send_heartbeat(self, event):
        url = f"{self.ground_url}/api/warehouse/drones/{self.drone_code}/heartbeat"
        payload = {
            "drone_code": self.drone_code,
            "status": self.status,
            "battery": self.battery,
            "position": self.position,
            "timestamp": time.time(),
        }
        try:
            resp = requests.post(url, json=payload, timeout=3)
            if resp.status_code == 200:
                rospy.logdebug(f"心跳成功: {resp.json()}")
            else:
                rospy.logwarn(f"心跳失败: {resp.status_code} - {resp.text}")
        except requests.exceptions.RequestException as e:
            rospy.logwarn(f"心跳异常: {e}")
            self._log_failed(url, payload, str(e))

    def _log_failed(self, url, payload, error):
        """将失败请求写入本地日志"""
        import os
        log_dir = os.path.join(os.path.dirname(__file__), "..", "logs")
        os.makedirs(log_dir, exist_ok=True)
        log_path = os.path.join(log_dir, "uav_ground_bridge_failed.jsonl")
        with open(log_path, "a") as f:
            f.write(json.dumps({
                "timestamp": time.strftime("%Y-%m-%dT%H:%M:%SZ", time.gmtime()),
                "endpoint": url,
                "method": "POST",
                "payload": payload,
                "error": error,
                "retry_count": 0,
            }) + "\n")
```

def upload_rfid_scan(ground_url, drone_code, tags, position, metadata):
