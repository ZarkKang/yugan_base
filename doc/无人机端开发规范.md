# 无人机端开发规范

> 版本：v3.1
> 编写日期：2026-07-06
> 主版本变更说明：
> - **新增 WebSocket 实时图传流协议**（替代完整视频文件上传）
> - **删除无人机端 QR 识别职责**（QR 识别已转移至基站端集中处理）
> - 航点视频帧标记机制（不切分视频，仅标记帧位置）
> - **API 统一到 `/api/drones/` 命名空间，路径参数从 drone_code(str) 改为 drone_id(int)**（v3.1）
> - **新增 `GET /api/drones/lookup` ID 反查接口**（v3.1）

## 一、系统架构与通信拓扑

### 1.1 网络拓扑

```
┌─────────────────────────────────────────────────────────────┐
│                        局域网 (192.168.1.x)                  │
│                                                             │
│  ┌─────────────────┐          ┌─────────────────┐         │
│  │   基站端        │          │   无人机端       │         │
│  │ Edge Server     │◄────────►│ Jetson NX       │         │
│  │ 192.168.1.200  │  HTTP/WS │ 192.168.1.201  │         │
│  │                 │  实时图传│                 │         │
│  └─────────────────┘          └─────────────────┘         │
│         │                               │                   │
│         │ Web管理界面                    │ 摄像头/雷达/传感器 │
│         ▼                               ▼                   │

└─────────────────────────────────────────────────────────────┘
```

### 1.2 通信通道

| 通道 | 协议 | 端点 | 用途 |
|------|------|------|------|
| 任务获取 | HTTP GET | `http://192.168.1.200:8080/api/drones/{drone_id}/tasks/available` | 拉取待执行任务 |
| 心跳上报 | HTTP POST | `http://192.168.1.200:8080/api/drones/heartbeat` | 每 5s 上报状态 |
| 任务进度 | HTTP POST | `http://192.168.1.200:8080/api/drones/{drone_id}/tasks/{task_id}/progress` | 航点完成时上报 |
| 任务完成 | HTTP POST | `http://192.168.1.200:8080/api/drones/{drone_id}/tasks/{task_id}/complete` | 任务结束时上报 |
| ID 反查 | HTTP GET | `http://192.168.1.200:8080/api/drones/lookup?drone_code=xxx` | drone_code→drone_id 映射（首次连接时调用） |
| **实时图传** | **WebSocket** | **`ws://192.168.1.200:8080/ws/video/{drone_id}`** | **JPEG 帧推流 + 航点帧标记** |
| 视频上传（降级） | HTTP POST | `http://192.168.1.200:8080/api/v1/videos/upload` | WS 不稳定时回退 |
| 固件查询 | HTTP GET | `http://192.168.1.200:8080/api/drones/firmware/latest` | 拉取最新固件版本 |

## 二、接口规范

### 2.1 HTTP REST 接口

#### 2.1.0 ID 反查（首次连接必需）

无人机只知自己的 `drone_code`（字符串编号），需先调用此接口获取数据库整数主键 `drone_id`，后续所有接口路径参数均使用 `drone_id`。

```http
GET /api/drones/lookup?drone_code=DRONE001
```

响应示例：
```json
{
  "success": true,
  "data": {
    "drone_id": 1,
    "drone_code": "DRONE001",
    "status": "idle"
  }
}
```

- **调用时机**：无人机启动后首次与基站通信时调用一次，缓存 `drone_id` 用于后续所有请求
- **缓存建议**：本地持久化 `drone_id`，避免每次重启都反查

#### 2.1.1 任务获取

```http
GET /api/drones/{drone_id}/tasks/available
```

响应示例：
```json
[
  {
    "task_id": "T001",
    "warehouse_id": "WH001",
    "scheduled_at": "2026-07-05T08:00:00Z",
    "total_waypoints": 50,
    "estimated_duration": 3600
  }
]
```

#### 2.1.2 心跳上报

```http
POST /api/drones/heartbeat
Content-Type: application/json
```

请求体：
```json
{
  "drone_id": 1,
  "battery": 85,
  "status": "flying",
  "position": {"x": 1.5, "y": 2.0, "z": 3.0},
  "current_task": "T001",
  "current_waypoint": "W015",
  "last_heartbeat": "2026-07-05T10:00:05Z"
}
```

- **频率**：每 5 秒一次
- **超时**：基站 30 秒未收到心跳则将无人机状态置为 `offline`

#### 2.1.3 任务进度上报

```http
POST /api/drones/{drone_id}/tasks/{task_id}/progress
```

请求体：
```json
{
  "scanned": 15,
  "total": 50,
  "normal_count": 14,
  "abnormal_count": 1,
  "current_waypoint": "W015"
}
```

每完成一个航点调用一次。

#### 2.1.4 任务完成

```http
POST /api/drones/{drone_id}/tasks/{task_id}/complete
```

请求体：
```json
{
  "summary": {
    "total_waypoints": 50,
    "scanned_waypoints": 50,
    "duration_sec": 3500,
    "abnormal_count": 2
  }
}
```

### 2.2 WebSocket 图传流协议（新增 — 重点章节）

#### 2.2.1 端点

```
ws://192.168.1.200:8080/ws/video/{drone_id}
```

- **路径参数**：`drone_id`（整数主键，通过 `GET /api/drones/lookup` 获取）
- **Query 参数**：`task_code`（可选，关联任务）；`token`（预留，当前允许匿名）
- **鉴权**：基站查 DB 确认 `drone_id` 存在，不存在则 `close(code=4404)`

#### 2.2.2 消息分类

无人机→基站的消息分两类，按 WebSocket opcode 区分：

| 类型 | opcode | 用途 |
|------|--------|------|
| **视频帧** | binary (opcode 2) | 纯 JPEG 字节流，无包装 |
| **控制消息** | text (opcode 1) | JSON 文本，必含 `type` 字段 |

**设计理由**：
- JPEG 二进制直传效率最高（避免 Base64 膨胀 33%）
- 控制消息用 JSON 文本便于调试与扩展

#### 2.2.3 控制消息类型

无人机→基站共 5 种控制消息：

##### (1) `stream_start` — 流开始

```json
{
  "type": "stream_start",
  "task_code": "TASK001",
  "session_token": "uuid-...",
  "camera": {"width": 1920, "height": 1080, "fps": 15},
  "timestamp": "2026-07-05T10:30:00Z"
}
```

- **必发**：建立连接后第一帧前发送
- 基站回 `{"type": "stream_start_ack", "session_id": "...", "status": "ok"}`

##### (2) `waypoint_enter` — 航点到达（关键消息）

```json
{
  "type": "waypoint_enter",
  "waypoint_id": "wp_001",
  "task_code": "TASK001",
  "shelf_code": "SHELF-001",
  "expected_sku": "SKU001",
  "position": {"x": 1.5, "y": 2.0, "z": 3.0},
  "sort_order": 3,
  "timestamp": "2026-07-05T10:30:15Z"
}
```

- **行为**：基站调用 `aggregator.mark_waypoint()` 追加 `waypoint_markers` 数组项
- **不切分视频**：单次 WS 会话产出单一视频文件，所有航点标记存入 `VideoData.waypoint_markers` JSON 数组
- 基站回 `{"type": "waypoint_marked", "waypoint_id": "wp_001", "frame_index": 1234}`

##### (3) `waypoint_leave` — 航点离开

```json
{
  "type": "waypoint_leave",
  "waypoint_id": "wp_001",
  "result_summary": {"qr_count": 1, "rfid_count": 4},
  "timestamp": "2026-07-05T10:30:45Z"
}
```

- **可选**：仅用于更新 Waypoint 状态为 `completed`，不影响视频聚合

##### (4) `stream_stop` — 流结束

```json
{
  "type": "stream_stop", "reason": "task_completed"}
```

- 收到后基站触发 `close_session()` → 落盘 + 创建 VideoData + 异步 QR 识别 + 交叉校验

##### (5) `heartbeat` — 心跳

```json
{
  "type": "heartbeat",
  "battery": 85,
  "status": "flying",
  "position": {"x": 1.5, "y": 2.0, "z": 3.0}
}
```

- 与 HTTP 心跳互补，WS 路径下的轻量级状态同步
- 基站回 `{"type": "heartbeat_ack", "timestamp": "..."}`

#### 2.2.4 基站→无人机消息

| 类型 | 字段 | 用途 |
|------|------|------|
| `stream_start_ack` | `session_id`, `status` | 确认流开始，分配会话 ID |
| `waypoint_marked` | `waypoint_id`, `frame_index` | 确认航点已标记 |
| `heartbeat_ack` | `timestamp` | 心跳响应 |
| `stream_closed` | `video_rec_id`, `file_path` | 流结束确认（含 VideoData ID） |
| `control` | `action`, `reason`, ... | 控制指令（如 `pause` / `switch_to_upload`） |

**降级指令示例**：
```json
{
  "type": "control",
  "action": "switch_to_upload",
  "reason": "ws_unstable",
  "fallback_url": "/api/v1/videos/upload"
}
```

收到此指令后，无人机应关闭 WS 连接，改用 `POST /api/v1/videos/upload` 上传剩余视频。

#### 2.2.5 关键字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `waypoint_id` | string | 航点唯一标识，对应 `Waypoint.waypoint_id` |
| `expected_sku` | string | 该航点预期 SKU（基站 QR 识别后会与之比对） |
| `position` | object | 无人机 3D 位置 `{x, y, z}`，单位米 |
| `frame_index` | int | 帧序号，由基站按收到顺序递增分配，写入 `waypoint_markers` |
| `timestamp` | ISO8601 | 消息时间戳 |
| `sort_order` | int | 航点扫描顺序号 |
| `shelf_code` | string | 关联货架编号（可选） |

#### 2.2.6 网络降级策略

| 触发条件 | 行为 |
|---------|------|
| WS 连续 3 次建立失败 | 直接走 multipart 上传 |
| WS 推流中连续丢帧 > 30s | 基站下发 `control: pause`，无人机降速 |
| WS 推流中帧缓冲溢出（>500 帧） | 基站下发 `control: switch_to_upload` |
| 基站主动关闭 WS | 无人机重试 3 次后回退 multipart |

## 三、数据格式规范

### 3.1 心跳数据结构

```python
{
    "drone_id": 1,                # 无人机整数主键（通过 lookup 获取）
    "battery": 85,                # 电量百分比 0-100
    "status": "flying",           # idle | flying | paused | error | charging
    "position": {
        "x": 1.5,                 # 米
        "y": 2.0,
        "z": 3.0
    },
    "current_task": "T001",       # 当前任务 ID（无任务时为 null）
    "current_waypoint": "W015",   # 当前航点 ID（无航点时为 null）
    "last_heartbeat": "2026-07-05T10:00:05Z"
}
```

### 3.2 任务进度上报结构

```python
{
    "scanned": 15,                # 已扫描航点数
    "total": 50,                  # 总航点数
    "normal_count": 14,           # 正常数
    "abnormal_count": 1,          # 异常数
    "current_waypoint": "W015"
}
```

### 3.3 航点数据结构（基站下发）

```python
{
    "waypoint_id": "W001",
    "grid_id": "G001",
    "position": {"x": 1.0, "y": 2.0, "z": 3.0},
    "camera_angle": 45,           # 摄像头俯仰角（度）
    "expected_skus": ["SKU001", "SKU002"],  # 该航点预期 SKU 列表
    "scan_timeout": 30            # 该航点扫描超时秒数
}
```

### 3.4 失败日志结构（本地缓存，可批量上传）

```python
{
    "timestamp": "2026-07-05T10:30:15Z",
    "level": "ERROR",             # INFO | WARN | ERROR
    "module": "ws_video_client",
    "message": "WebSocket connection refused",
    "context": {
        "drone_id": "DRONE001",
        "task_code": "T001",
        "retry_count": 3
    }
}
```

## 五、技术参数与约束

### 5.1 视频流参数

| 参数 | 默认值 | 范围 | 说明 |
|------|--------|------|------|
| FPS | 15 | 10-30 | 推荐平衡带宽与流畅度 |
| 分辨率 | 1920×1080 | 1280×720 ~ 3840×2160 | 网络差时降为 720p |
| JPEG 质量 | 85 | 70-95 | 建议 ≥ 70 |
| 单帧字节数 | ≥ 5KB | - | 小于 30 字节视为无效帧丢弃 |
| 编码格式 | JPEG | - | 仅支持 JPEG，不支持 PNG/H.264 |

### 5.2 网络参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 心跳间隔 | 5s | HTTP 心跳 |
| 心跳超时 | 30s | 基站判定离线阈值 |
| WS 重连间隔 | 1s/2s/4s/8s | 指数退避，最大 30s |
| WS 重连次数 | 3 | 超过后回退 multipart 上传 |
| TCP keepalive | 60s | 操作系统级 |

### 5.3 资源约束

| 资源 | 上限 | 说明 |
|------|------|------|
| 本地视频缓存 | 500MB | 超过后滚动覆盖最旧文件 |
| 失败日志缓存 | 1000 条 | 超过后滚动覆盖 |
| WS 帧缓冲队列 | 100 帧 | 满时丢帧并记日志 |
| 单次任务时长 | 1 小时 | 超时强制返航 |

## 七、测试标准

### 7.1 WS 推流测试用例

#### TC-WS-001：基础推流

- **前置**：`DRONE001` 已注册，任务 `T001` 已创建
- **步骤**：
  1. 建立 WS 连接 `ws://192.168.1.200:8080/ws/video/1?task_code=T001`（1 为 drone_id）
  2. 发送 `stream_start`
  3. 推送 100 帧 JPEG（1280×720，每帧间隔 66ms）
  4. 发送 `stream_stop`
- **预期**：
  - 基站返回 `stream_start_ack` / `stream_closed`
  - `storage/videos/T001/DRONE001/ws_{session_id}.mp4` 文件存在
  - DB 中 `VideoData` 记录 `source='ws_stream'`，`processing_status='completed'`

#### TC-WS-002：航点帧标记

- **前置**：同 TC-WS-001
- **步骤**：
  1. 建立连接
  2. 推 30 帧
  3. 发送 `waypoint_enter(wp_001, expected_sku=SKU001)`
  4. 推 30 帧
  5. 发送 `waypoint_enter(wp_002, expected_sku=SKU002)`
  6. 推 30 帧
  7. 发送 `stream_stop`
- **预期**：
  - DB 中 `VideoData.waypoint_markers` JSON 数组长度为 2
  - `markers[0].waypoint_id == "wp_001"`
  - `markers[1].waypoint_id == "wp_002"`
  - **不创建多个 VideoData 行**（验证"不切分视频"语义）

#### TC-WS-003：网络降级

- **前置**：WS 连接已建立
- **步骤**：基站下发 `control: switch_to_upload`，无人机应关闭 WS 并改走 multipart
- **预期**：`POST /api/v1/videos/upload` 收到视频，`VideoData.source='upload'`

#### TC-WS-004：断线重连

- **前置**：WS 连接已建立
- **步骤**：物理断网 5 秒，恢复网络
- **预期**：无人机按 1s/2s/4s 退避重连，重连成功后用新 `stream_session_id`

## 八、代码示例

### 8.1 Python WS 客户端最小实现

```python
"""
无人机端 WS 视频推流客户端（参考实现）
依赖：pip install websockets opencv-python requests
"""
import asyncio
import json
import cv2
import websockets
import requests


class DroneVideoStreamClient:
    def __init__(self, base_url: str, drone_code: str, task_code: str = None):
        self.base_url = base_url  # ws://192.168.1.200:8080
        self.drone_code = drone_code  # 无人机已知编号
        self.drone_id = None  # 通过 lookup 获取的整数 PK
        self.task_code = task_code
        self.ws = None
        self.frame_index = 0

    async def resolve_drone_id(self):
        """首次连接时调用：drone_code → drone_id 反查"""
        http_url = f"http{self.base_url[2:]}"  # ws:// → http://
        resp = requests.get(f"{http_url}/api/drones/lookup",
                            params={"drone_code": self.drone_code})
        data = resp.json()
        if data.get("success"):
            self.drone_id = data["data"]["drone_id"]
            print(f"[WS] drone_code={self.drone_code} → drone_id={self.drone_id}")
        else:
            raise ValueError(f"drone_code={self.drone_code} 未在基站注册")

    async def connect(self):
        if self.drone_id is None:
            await self.resolve_drone_id()
        url = f"{self.base_url}/ws/video/{self.drone_id}"
        if self.task_code:
            url += f"?task_code={self.task_code}"
        self.ws = await websockets.connect(url)
        # 发送 stream_start
        await self.ws.send(json.dumps({
            "type": "stream_start",
            "task_code": self.task_code,
            "camera": {"width": 1920, "height": 1080, "fps": 15},
            "timestamp": _now_iso()
        }))
        # 等待 ack
        ack = json.loads(await self.ws.recv())
        assert ack["type"] == "stream_start_ack"
        self.session_id = ack["session_id"]
        print(f"[WS] 流已启动 session_id={self.session_id}")

    async def push_frame(self, frame: bytes):
        """推送一帧 JPEG"""
        await self.ws.send(frame)  # binary
        self.frame_index += 1

    async def mark_waypoint(self, waypoint_id: str, expected_sku: str = None,
                            position: dict = None):
        """到达航点时调用 — 不切分视频，仅标记帧位置"""
        await self.ws.send(json.dumps({
            "type": "waypoint_enter",
            "waypoint_id": waypoint_id,
            "task_code": self.task_code,
            "expected_sku": expected_sku,
            "position": position or {},
            "timestamp": _now_iso()
        }))
        ack = json.loads(await self.ws.recv())
        assert ack["type"] == "waypoint_marked"
        print(f"[WS] 航点 {waypoint_id} 已标记 frame_index={ack['frame_index']}")

    async def stop(self, reason: str = "task_completed"):
        await self.ws.send(json.dumps({"type": "stream_stop", "reason": reason}))
        closed = json.loads(await self.ws.recv())
        assert closed["type"] == "stream_closed"
        print(f"[WS] 流已关闭 video_rec_id={closed.get('video_rec_id')}")
        await self.ws.close()

    async def heartbeat(self, battery: int, status: str, position: dict):
        await self.ws.send(json.dumps({
            "type": "heartbeat",
            "battery": battery,
            "status": status,
            "position": position
        }))


def _now_iso() -> str:
    from datetime import datetime, timezone
    return datetime.now(timezone.utc).isoformat()


# 使用示例
async def main():
    client = DroneVideoStreamClient(
        base_url="ws://192.168.1.200:8080",
        drone_code="DRONE001",  # 无人机已知编号
        task_code="TASK001"
    )
    await client.connect()  # 内部自动 resolve_drone_id

    cap = cv2.VideoCapture(0)  # 摄像头设备
    try:
        # 推 100 帧
        for i in range(100):
            ret, frame = cap.read()
            if not ret:
                break
            _, jpeg = cv2.imencode(".jpg", frame, [cv2.IMWRITE_JPEG_QUALITY, 85])
            await client.push_frame(jpeg.tobytes())
            await asyncio.sleep(0.066)  # ~15 FPS

            # 第 30 帧到达航点
            if i == 30:
                await client.mark_waypoint(
                    waypoint_id="wp_001",
                    expected_sku="SKU001",
                    position={"x": 1.5, "y": 2.0, "z": 3.0}
                )

            # 每 10 帧发心跳
            if i % 10 == 0:
                await client.heartbeat(
                    battery=85 - i // 10,
                    status="flying",
                    position={"x": i * 0.1, "y": 0, "z": 1.0}
                )

        await client.stop()
    finally:
        cap.release()


if __name__ == "__main__":
```
