## 三、异常判定引擎（优先级：🔴高）

### 3.1 判定规则

```
┌─────────────────────────────────────────────────────┐
│                  库存比对判定                         │
├─────────────────────────────────────────────────────┤
│                                                     │
│  视觉识别SKU ──┬── 位置匹配 → 正常 ✓                │
│               │                                     │
│               ├── 位置错位 → 错位异常 ⚠️            │
│               │                                     │
│               ├── 数量不足 → 缺货异常 ⚠️            │
│               │                                     │
│               ├── 数量多余 → 多货异常 ⚠️            │
│               │                                     │
│               └── 重复扫码 → 重复码异常 ⚠️          │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### 3.2 判定状态码

| 状态 | 代码 | 说明 |
|------|------|------|
| 正常 | `NORMAL` | SKU与位置匹配 |
| 错位 | `MISPLACED` | SKU在错误位置 |
| 缺货 | `MISSING` | 预期SKU未找到 |
| 多货 | `EXTRA` | 多余SKU |
| 重复 | `DUPLICATE` | 重复扫码 |
| 异常 | `ERROR` | 识别错误 |

### 3.3 建议实现

```python
# app/services/verification_engine.py
from enum import Enum
from dataclasses import dataclass
from typing import Optional

class VerificationStatus(str, Enum):
    NORMAL = "normal"
    MISPLACED = "misplaced"
    MISSING = "missing"
    EXTRA = "extra"
    DUPLICATE = "duplicate"
    ERROR = "error"

@dataclass
class VerificationResult:
    status: VerificationStatus
    expected_sku: Optional[str]
    actual_sku: Optional[str]
    expected_location: str
    actual_location: str
    confidence: float
    evidence_images: list[str]

class VerificationEngine:
    def __init__(self, db_session):
        self.db = db_session

    def verify(self, scan_data: dict) -> VerificationResult:
        """
        核心判定逻辑：
        1. 根据位置查询预期SKU列表
        2. 比对视觉识别结果
        3. 根据比对结果返回判定
        """
        waypoint_id = scan_data['waypoint_id']
        actual_sku = scan_data['qr_data']

        # 查询预期SKU
        expected_skus = self.get_expected_skus(waypoint_id)

        if actual_sku in expected_skus:
            return VerificationResult(
                status=VerificationStatus.NORMAL,
                expected_sku=actual_sku,
                actual_sku=actual_sku,
                confidence=scan_data['confidence']
            )
        elif self.is_misplaced(actual_sku, waypoint_id):
            return VerificationResult(
                status=VerificationStatus.MISPLACED,
                expected_sku=expected_skus[0] if expected_skus else None,
                actual_sku=actual_sku,
                confidence=scan_data['confidence']
            )
        elif self.is_duplicate(actual_sku, scan_data['task_id']):
            return VerificationResult(
                status=VerificationStatus.DUPLICATE,
                expected_sku=expected_skus[0] if expected_skus else None,
                actual_sku=actual_sku,
                confidence=scan_data['confidence']
            )
        else:
            return VerificationResult(
                status=VerificationStatus.EXTRA,
                expected_sku=expected_skus[0] if expected_skus else None,
                actual_sku=actual_sku,
                confidence=scan_data['confidence']
            )
```

## 五、二维码识别增强（优先级：🟡中）

### 5.1 当前问题

- 仅使用基础高斯模糊预处理
- 缺乏多尺度识别
- 模糊图像识别率低（约20%）

### 5.2 改进方案

```python
# app/services/qr_service_enhanced.py
import cv2
import numpy as np
from pyzbar.pyzbar import decode as pyzbar_decode
from typing import Optional, Tuple

class EnhancedQRDecoder:
    """
    增强版二维码解码器
    支持：多尺度、多策略、深度学习增强
    """

    def __init__(self):
        self.scales = [0.5, 0.75, 1.0, 1.25, 1.5, 2.0]
        self.preprocess_strategies = [
            'original',           # 原图
            'gaussian_blur',       # 高斯模糊
            'bilateral_filter',    # 双边滤波（保边去噪）
            'histogram_eq',        # 直方图均衡化
            'adaptive_threshold',  # 自适应阈值
            'sharpen',             # 锐化
        ]

    def decode(self, image_path: str) -> Optional[Tuple[str, float]]:
        """
        增强解码
        返回: (解码结果, 置信度)
        """
        image = cv2.imread(image_path)
        if image is None:
            return None

        gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)

        for scale in self.scales:
            # 多尺度缩放
            if scale != 1.0:
                resized = cv2.resize(gray, None, fx=scale, fy=scale)
            else:
                resized = gray

            # 多预处理策略
            for strategy in self.preprocess_strategies:
                processed = self._preprocess(resized, strategy)

                # 尝试解码
                result = self._decode_single(processed)
                if result:
                    return result

        return None

    def _preprocess(self, image: np.ndarray, strategy: str) -> np.ndarray:
        """图像预处理"""
        if strategy == 'original':
            return image
        elif strategy == 'gaussian_blur':
            return cv2.GaussianBlur(image, (3, 3), 0)
        elif strategy == 'bilateral_filter':
            return cv2.bilateralFilter(image, 9, 75, 75)
        elif strategy == 'histogram_eq':
            return cv2.equalizeHist(image)
        elif strategy == 'adaptive_threshold':
            return cv2.adaptiveThreshold(
                image, 255,
                cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
                cv2.THRESH_BINARY, 11, 2
            )
        elif strategy == 'sharpen':
            kernel = np.array([[-1,-1,-1], [-1,9,-1], [-1,-1,-1]])
            return cv2.filter2D(image, -1, kernel)
        return image

    def _decode_single(self, image: np.ndarray) -> Optional[Tuple[str, float]]:
        """单次解码尝试"""
        barcodes = pyzbar_decode(image)
        if barcodes:
            # 返回解码结果和置信度（基于图像质量评估）
            confidence = self._estimate_confidence(image)
            return (barcodes[0].data.decode('utf-8'), confidence)
        return None

    def _estimate_confidence(self, image: np.ndarray) -> float:
        """估计图像/识别置信度（基于拉普拉斯方差）"""
        laplacian = cv2.Laplacian(image, cv2.CV_64F)
        variance = laplacian.var()
        # 将方差映射到0-1区间
        return min(1.0, variance / 1000.0)
```

## 八、建议

1. **优先实现核心闭环**：任务创建 → 航点扫描 → 数据接收 → 异常判定 → 报告生成
2. **渐进式开发**：每完成一个模块就进行测试，不要一次性改动太多
3. **预留扩展接口**：即使当前不接入PLC/WMS，也应预留接口便于后续扩展
4. **日志与监控**：关键操作添加日志，便于问题排查
